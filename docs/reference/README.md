# Reference

The committed part of the notes tree: standing material on how the system works.
Everything else under `docs/` is private and gitignored, so nothing here links out of `reference/`.

`internal/` holds pages written here, describing how the system fits together on `main`; they are rewritten in place when the code moves.
`external/` holds sources someone else wrote that the project cites; they are never edited, only replaced with a newer version.

| File | What It Is |
|---|---|
| [`internal/architecture.md`](internal/architecture.md) | Namespace layering, invariants and design decisions; read before any structural change |

Milestone walkthroughs and explainers are not reference; they live in the private notes.
